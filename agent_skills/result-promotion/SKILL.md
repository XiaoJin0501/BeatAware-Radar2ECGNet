# Result Promotion

Use only when promoting:

```text
pilot -> final
publishable=false -> publishable=true
```

Required evidence:

- complete planned folds;
- locked protocol;
- clean commit;
- experiment spec;
- run manifest;
- prediction artifacts or reproducible artifact paths;
- metric audit;
- fair baseline comparison;
- claim ledger update.

If any requirement is missing, promotion is denied.
