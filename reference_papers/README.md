# Reference Papers

This directory stores local background papers for the Q1 journal extension.

PDF files are intentionally ignored by Git. They are not executable
dependencies and should not be treated as experiment outputs. When citing a
paper result, verify the dataset, protocol, output definition, and metric
definition before adding it to a manuscript table.

Important current caveats:

- The local MMECG public dataset is not the unrelated dataset also called
  MMECG in some published papers.
- radarODE-MTL paper results should be compared under its long-term ECG
  assembly protocol, not only under the local Shape-200 subtask.
- CR_RVS / Nature results should be reported as 5-fold subject-independent
  validation in this project.
