# Repository Archive

Files here are retained for provenance and reproducibility; they are not active
entry points. Nothing in this tree should be imported by production training
code or used as manuscript evidence without being restored, reviewed, and
registered again.

- `legacy_experiments/`: local result trees moved from `experiments_mmecg/`.
  The large artifacts remain untracked; `ARCHIVE_MANIFEST.tsv` and the canonical
  experiment registry preserve their locations.
- `legacy_scripts/`: obsolete audits, smokes, pilots, and miscellaneous runners.
- `legacy_tests/`: tests tied to those historical entry points.
- `deprecated_docs/`: superseded roadmaps and drafts.

Archive moves are reversible. Do not delete these trees as routine cleanup.
