# Deprecated documentation

These files are retained for provenance only. They are not active contracts,
roadmaps, experiment authorizations, or manuscript evidence sources.

The authoritative roadmap is
`docs/Q1_JOURNAL_MASTER_PLAN.md`; the active scientific contracts are
`docs/RESEARCH_CONTRACT.md`, `docs/DATA_PROTOCOL.md`, and
`docs/METRIC_CONTRACT.md`.

## Why these documents were archived

- `ALIGNMENT_DESIGN.md` proposed learned `δ(t)`/delay warping as the central
  contribution. Controlled experiments did not close the continuous gap.
- `ASSEMBLY_DESIGN.md` and `ADR-0002-long-ecg-assembly.md` promoted the Route C
  anchor/OLA path. Its headline oracle evidence was withdrawn and predicted
  assembly failed to generalize.
- Old experiment plans, matrices, blueprints, structure documents, and result
  skeletons contain superseded action items or the deprecated REM-AlignNet name.
- Freeze/tuning, timing-gate, morphology-consistency, and pilot disk documents
  describe completed or rejected branches, not pending work.

Historical claims must be read through `docs/PAPER_CLAIM_LEDGER.md`, which
records the retractions and scope boundaries. Do not restore or execute a route
from this directory without an explicit new user decision and a new registered
specification.
