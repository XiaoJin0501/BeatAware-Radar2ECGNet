# Documentation map

For the current paper, use:

1. `paper/PAPER_FACTS.md` — source-verified facts, missing evidence and model-lineage caveats.
2. `paper/RESULTS_MANIFEST.md` — latest complete numeric results and producing commits.
3. `paper/` — manuscript drafts, figures, tables, source data and reports.
4. `CLEANUP_20261104.md` — what was removed from the working tree, what is protected and how to restore.

The small set of top-level contracts required by `AGENTS.md` remains. Existing user edits
to the metric contract, journal roadmap and literature ledgers were preserved unchanged.
Historical protocol/audit documents were relocated externally; immutable audit evidence
explicitly referenced by project instructions remains under `audits/`.

A dated source-data directory is not automatically obsolete. Current tables and figures
still read many such files; they were preserved in this cleanup.
