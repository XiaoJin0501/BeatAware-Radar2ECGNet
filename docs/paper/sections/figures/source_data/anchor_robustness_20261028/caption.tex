\caption{Anchor-robustness analysis of REM-Net on (a) MMECG and (b) CR\_RVS.
Only the phase-grid boundaries are perturbed; model features, predicted event
probabilities, weights, and reference Shape-200 targets remain fixed.
The horizontal axis is the realised mean absolute error of both boundaries,
not the nominal Gaussian standard deviation. The first curve point uses
reference anchors. Five repeat estimates are averaged within each subject;
shading and star whiskers show subject-bootstrap 95\% confidence intervals.

matched central R--R pairs, whereas its PCC includes all windows. The dashed

This is an oracle-anchor sensitivity diagnostic, not deployable performance
