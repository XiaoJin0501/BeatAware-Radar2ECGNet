# Change Handoff

Use after a meaningful code, protocol, experiment, or paper change.

Create or update:

```text
docs/changes/YYYY-MM-DD-<slug>.md
```

Include:

- why the change was made;
- files changed;
- scientific meaning;
- whether it changes protocol or metrics;
- tests/commands and results;
- affected previous experiments;
- what the next agent should do.

Do not use this for tiny typo-only changes unless they affect instructions.
